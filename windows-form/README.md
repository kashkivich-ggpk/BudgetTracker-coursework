# Учёт личных финансов (Budget Tracker)

## Готовый установщик

Установщик Windows x64:

```text
installer/output/FinancialAssistantSetup.exe
```

Приложение подключается к Supabase через HTTPS Data API. Пароль PostgreSQL и
ODBC-драйвер пользователю не требуются. При первом запуске создаётся уникальный
`client_id`, который хранится в:

```text
%LocalAppData%\FinancialAssistant\client_id.txt
```

Этот идентификатор отделяет данные одной установки от данных других
пользователей и сохраняется при обновлении приложения.

Настольное приложение **Windows Forms на C++/CLI** для учёта личных доходов и
расходов. Реализованы все пункты технического задания: регистрация операций,
категории, фильтрация по датам, расчёт баланса, лимиты с предупреждениями,
сохранение в файл и круговая диаграмма структуры расходов.

> ⚠️ **Платформа.** C++/CLI Windows Forms компилируется и запускается **только в
> Windows** при помощи Visual Studio (компилятор MSVC `cl /clr`). На macOS/Linux
> проект не собирается. Код написан, но **не был собран в этой среде** — сборку
> нужно выполнить в Windows по инструкции ниже.

## Требования

- **Windows 10/11**
- **Visual Studio 2026 Insiders** с компонентами:
  - «Разработка классических приложений на C++» (Desktop development with C++)
  - «Поддержка C++/CLI» (C++/CLI support for v145 build tools)
- **.NET Framework 4.8** (targeting pack входит в VS 2022; при необходимости
  можно переключить на 4.7.2 в свойствах проекта).

## Сборка и запуск

1. Откройте `BudgetTracker.sln` в Visual Studio 2022.
2. Выберите конфигурацию **Debug** или **Release**, платформу **x64** (или x86).
3. Соберите: меню **Сборка → Собрать решение** (Ctrl+Shift+B).
4. Запустите: **F5** (с отладкой) или **Ctrl+F5**.

Сборка из командной строки (Developer Command Prompt for VS 2022):

```bat
msbuild BudgetTracker.sln /p:Configuration=Release /p:Platform=x64
```

Исполняемый файл появится в `BudgetTracker\x64\Release\BudgetTracker.exe`.

## Хранение данных

Данные сохраняются автоматически — **после каждого изменения** и **при закрытии
окна** — в текстовый файл `budget_data.txt` рядом с `.exe`. При запуске история и
настройки категорий/лимитов читаются из этого файла. Формат — простой текст в
кодировке UTF-8 с секциями `[CATEGORIES]`, `[LIMITS]`, `[TRANSACTIONS]`.

При первом запуске создаётся стартовый набор категорий
(Зарплата, Продукты, Транспорт, Развлечения, Коммунальные платежи, Прочее).

## Соответствие техническому заданию

| Пункт ТЗ | Реализация |
|---|---|
| 1. Регистрация транзакций (сумма + комментарий) | Вкладка «Операции», группа «Новая операция» → `btnAdd_Click` |
| 1. Типизация (доход/расход) | Выпадающий список «Тип» (`cmbType`) |
| 1. Хронологический учёт (выбор/смена даты) | `DateTimePicker` + кнопка «Редактировать выбранное» |
| 1. Классификация (категория) | Список «Категория» (`cmbCategory`) |
| 1. Отображение перечня | Таблица `grid` → `RefreshGrid()` |
| 2. Временная фильтрация (от/до) | Группа «Фильтр по периоду» → `btnApplyFilter_Click` |
| 2. Расчёт баланса | `RefreshBalance()` (все доходы − все расходы) |
| 2. Агрегация по категориям | Вкладка «Статистика», таблица `gridAgg` → `RefreshAggregation()` |
| 3. Управление лимитами | Вкладка «Категории и лимиты» → `btnSetLimit_Click` |
| 3. Контроль превышения + предупреждение | Проверка в `btnAdd_Click` (MessageBox при превышении) |
| 3. Визуальное разграничение (цвет) | Зелёный фон у доходов, красный — у расходов в `RefreshGrid()` |
| 4. Экспорт данных в файл | `SaveData()` (после изменений и при закрытии) |
| 4. Инициализация из файла | `LoadData()` в конструкторе формы |
| 4. Управление справочниками | Добавление/переименование категорий (`btnAddCategory_Click`, `btnRenameCategory_Click`) |
| 5. Графическая отчётность (диаграмма) | Круговая диаграмма расходов на панели `chartPanel` → `chartPanel_Paint` (GDI+) |

## Примечания по реализации

- Денежные суммы хранятся в типе `System::Decimal` (без ошибок округления).
- Парсинг/формат чисел и дат — через `CultureInfo::InvariantCulture`, поэтому
  файл данных не зависит от региональных настроек.
- Поддерживается ввод суммы как через точку (`123.45`), так и через запятую
  (`123,45`).
- Кириллица в исходниках компилируется корректно благодаря флагу `/utf-8`
  (задан в `.vcxproj`).

## Возможные проблемы при сборке

- **Ошибка компоновщика про точку входа** (`unresolved external symbol main`/`WinMain`)
  или **появляется лишнее консольное окно.** В проекте уже заданы
  `Linker → System → SubSystem = Windows` и `Linker → Advanced → Entry Point = main`
  (элемент `<EntryPointSymbol>main</EntryPointSymbol>` в `.vcxproj`) — это штатная
  настройка для C++/CLI Windows Forms. Если среда всё же ругается, как запасной
  вариант поставьте `SubSystem = Console` (приложение запустится, но рядом будет
  служебное консольное окно).
- **Нет поддержки C++/CLI.** В Visual Studio Installer добавьте компонент
  «C++/CLI support for v145 build tools».
- **Нет .NET Framework 4.8 targeting pack.** Либо доустановите его, либо в свойствах
  проекта (`Свойства → Общие → .NET Target Framework Version`) выберите 4.7.2.
