# Аудит установки «Финансового помощника»

## Проверено

- Release-сборка создаётся для `x64`.
- Приложению требуется .NET Framework 4.8.
- Установщик включает Microsoft Visual C++ Runtime x64.
- Подключение выполняется через Supabase Data API по HTTPS.
- ODBC-драйвер и пароль PostgreSQL не требуются.
- В конфигурации находятся только URL и публичный `sb_publishable_` key.
- В базе присутствуют все пять таблиц приложения.
- Все таблицы разделены колонкой `client_id`.
- Загрузка выполняется одним RPC-запросом.
- Сохранение выполняется одним транзакционным RPC-запросом.
- Тест создания, чтения и очистки отдельного профиля через Data API выполнен.
- `client_id` создаётся один раз в `%LocalAppData%\FinancialAssistant` и
  сохраняется при обновлении или переустановке приложения.

## Готовый установщик

```text
installer\output\FinancialAssistantSetup.exe
```

Установщик:

- поддерживает только x64 Windows;
- устанавливает приложение в Program Files;
- создаёт ярлыки;
- устанавливает VC++ Runtime при необходимости;
- не удаляет индивидуальный `client_id` при обновлении или удалении программы.

## Проверка текущей Release-сборки

Запустите:

```powershell
powershell.exe -ExecutionPolicy Bypass -File deployment\smoke_test.ps1
```

Сценарий не выводит пароль и проверяет Release EXE, драйвер, подключение,
таблицы и индивидуальный идентификатор.
